대시보드 계정 발급

관리자가 사용자에게 계정을 만들어줄 때 쓰는 도우미야. 계정 생성은 Supabase Authentication 화면에서 직접 진행해야 해.

닉네임을 입력해줘.

Supabase 새 프로젝트 → Authentication → Users → Add user에서 이 내부용 이메일과 개인 비밀번호를 등록해. 실제 사용자는 이메일을 몰라도 돼. 이 주소는 메일을 받을 수 없으므로 이메일 인증·비밀번호 찾기는 쓸 수 없고, 비밀번호 변경은 관리자가 직접 진행해야 해.

※ 4자리 PIN은 권장하지 않아. 최소 10자리 이상의 각자 다른 비밀번호를 사용해줘. 이 페이지는 비밀번호를 수집하거나 저장하지 않아.
