# JEI Dashboard V70

## 추가된 기능
- `pandemic-legacy-s2.html` 신규 생성
- GAME ARCHIVE 공통 헤더에 `팬데믹 S2 로그 🔒` 추가
- 팬데믹 S2 페이지는 S1 로그 구조를 기준으로 구성하되 `레거시 일정` 영역은 제외
- 플레이어: 다은(핑크) / 한철(블랙) / 승민(블루) / 제이(화이트)
- S2용 캠페인 상태: 현재 월, 도전, 배급 수준, 직전 결과, 목표/추가규칙/영구상태, 다음 게임 메모
- 회차 기록 + 사진 1~3장
- 시즌2 감염 카드 더미 트래커
  - 시작 공개 도시 9곳 × 감염 카드 3장
  - 도시별 `덱 / 버린 더미 / 최상단 그룹 / 총 카드` 장수 표시
  - 유행병 시 맨 아래 도시 선택 → 버린 더미를 새 최상단 그룹으로 자동 전환
  - 도시/감염카드 장수 직접 추가·보정
  - 버린 더미 카드 → 게임 종료 영역 이동 지원
  - 새 게임 초기화 시 모든 카드를 다시 한 더미로 합침
  - 되돌리기 지원
- S2 플레이어 덱/유행병 카운터
  - 캠페인 진행에 따라 덱 구성이 변할 수 있어 시작 장수를 직접 입력
  - 기본 유행병 카드 수 5, 필요 시 수정 가능
