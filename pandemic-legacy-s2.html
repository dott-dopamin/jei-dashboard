감염 카드 더미 트래커

첨부한 엑셀 트래커 구조를 웹에 맞게 재구성했어요. 도시별 영구 카드 수 · 감염 차수 1~5 · 현재 남은 장수와 다음 감염 확률을 한 화면에서 관리합니다.

현재 감염 차수
블루 옐로우 블랙 레드 기타 카드 도시/카드명을 클릭하면 현재 감염 차수에 1장이 기록되고, 다시 클릭하면 취소됩니다.
카드 추가
도시 / 카드 총 카드 1차 2차 3차 4차 5차 현재 남음 수정
사용법 · 표의 도시/카드명을 누르면 현재 감염 차수에 1장이 기록되고, 다시 누르면 그 기록이 취소됩니다. 도시명 오른쪽에는 다음 감염 후보 확률이 함께 표시됩니다. 같은 도시가 같은 차수에 2장 이상 나온 경우에는 수정에서 직접 보정하세요. 유행병 카드가 나오면 유행병 발생 · 덱 하단 체크를 눌러 실제로 덱 맨 아래에서 나온 카드를 선택하세요.

유행병 발생 · 덱 하단 카드 체크

실제로 감염덱 맨 아래에서 나온 카드를 선택하세요. 선택한 카드는 현재 감염 차수에 1장 기록되고, Intensify 처리 기준으로 다음 감염 차수로 이동합니다.

도시 / 감염 카드 편집

캠페인 진행 중 공개된 도시는 직접 추가할 수 있고, 도시별 카드도 덱 / 버린 더미 / 게임 종료 영역 사이에서 직접 조정할 수 있어요. 실수 보정이나 카드 영구 제거 같은 상황에 사용하세요.
덱→버림 : 덱에 있는 카드 1장을 버린 더미로 이동버림→덱 : 버린 카드 1장을 그룹 1로 복구버림→종료 : 카드 1장을 이번 게임에서 제외
